# Security Policy

WASP is pre-1.0 and does not yet publish release binaries. Security fixes are developed against the latest version on the default branch; no older version is currently designated as supported.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** option in the repository's Security tab when private vulnerability reporting is enabled. Do not publish exploit details, target data, or sensitive scan output in a public issue or discussion. If private reporting is unavailable, open a minimal issue asking the maintainers for a private reporting channel and do not include vulnerability details.

Include the affected commit or version, impact, prerequisites, and a minimal reproduction against a local test fixture where possible. Allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. There is no guaranteed response or remediation SLA at this stage.

WASP is intended only for authorized inspection. Its reports are advisory and cannot establish that a system is free of vulnerabilities. Active scanning is not implemented in the current release. Please do not probe third-party systems while investigating or demonstrating a report.
